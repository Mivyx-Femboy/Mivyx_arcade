Mivyx is a game launcher with a built-in jukebox. Add your games, pick your music, and play on whatever you have in your hand.

- **Same hub everywhere.** Phone, tablet, PC, Linux box, browser.
- **Updates itself.** Every app opens the newest hub straight from this repository, so a new game or song shows up without a new download.

- **Mobile and Desktop layouts.** The hub picks one for you and shows its version number at start.

## 🎵 Base music: what you need to do

The base songs are the playlist that plays for **everyone, on every version** (admin, public, guest, mobile). You manage it with one file, `base-songs.json`. No re-export needed. Changes show up the next time the hub opens.

**1. Pick how each song gets in**

| You have | You add |
| --- | --- |
| An MP3 file | `{ "name": "My song", "url": "music/my-song.mp3" }` |
| A YouTube link | `{ "name": "Chill mix", "url": "https://www.youtube.com/watch?v=VIDEOID" }` |

**2. MP3 only: upload the file**
Open the repo, go into the **music** folder, then **Add file → Upload files**, drag the mp3 in and **Commit changes**.
Use simple names like `my-song.mp3` (no spaces). The web uploader accepts files up to 25 MB each.

**3. Add the song to the list**
Open `base-songs.json`, click the **✏️ pencil**, then write your list and **Commit changes**:

```json
[
  { "name": "My song", "url": "music/my-song.mp3" },
  { "name": "Chill mix", "url": "https://www.youtube.com/watch?v=VIDEOID" }
]
```

**4. Check it worked**
Open the **Actions** tab. **Check music list** shows a green ✓ when every song is found, or a red ✗ that names the song with the problem. Then reload the hub. Your songs are in the music panel. In an app, close it and open it again.

<details>
<summary><b>If a song doesn't show up</b></summary>

<br>

- The list must start with `[` and end with `]`, with a comma after every song **except the last**.
- Use straight quotes `"like this"`, not curly ones.
- The file name in `url` must match the uploaded file exactly, including capitals: `music/My-Song.mp3` is not `music/my-song.mp3`.
- YouTube songs play when the hub is on a web address (the live site, the apps, the home-screen app). They won't play from an HTML file saved on your computer. If one won't play inside an app, use an MP3 instead.
- Only upload music you have the right to share. A public repository is public.

</details>
